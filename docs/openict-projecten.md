# Open-ICT-projecten (september 2026)

De projecten (squads) van Open-ICT vanaf september 2026, met hun opdrachtgever. Het dashboard leest deze tabel voor de knop "Open-ICT-projecten (sept 2026) toevoegen" op de pagina Nieuw project ([spec 012](../features/012-projecten/spec.md)). Houd de vorm van de tabel gelijk: één project per regel, `| Nr | Projectnaam | Opdrachtgever | Weergave |`. De kolom *Weergave* is de ingekorte opdrachtgever en projectnaam; het dashboard zet er het nummer tussen haakjes achter. De nummers hoeven niet oplopend te zijn (soms gaat een project op het laatste moment niet door, en willen we de bestaande projectnummering aanhouden).
