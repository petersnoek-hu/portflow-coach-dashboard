# Beroepsrollen

Elke student heeft precies één **primaire** beroepsrol en optioneel een of meer **secundaire** beroepsrollen. Bij elke beroepsrol hoort een **gilde**, waarin de gildemeester de productvaardigheden (OC, KO, JKO, KPM) beoordeelt; het gilde van een student volgt uit zijn primaire beroepsrol. Zie ook [begrippen](begrippen.md).

In LEF staan per beroepsrol voorbeelden van producten die bij die rol passen (zie [KPM in vaardigheden-niveaus-LEF.md](vaardigheden-niveaus-LEF.md#kpm)).

| Code | Beroepsrol |
|---|---|
| **UX** | UI/UX designer |
| **BIT** | Business IT engineer |
| **CS** | Cybersecurity engineer |
| **CI** | Cloud & Infra engineer |
| **FE** | Front-end developer |
| **BE** | Back-end developer |
| **AI** | AI engineer |
| **GD** | Game developer |
| **TI** | Embedded technologie engineer |

Deze negen rollen zijn de **standaard** in het dashboard. De gebruiker kan rollen toevoegen, bewerken en verwijderen (zie [gegevensmodel.md](gegevensmodel.md#beroepsrol)). Gebruik deze codes en namen; de afwijkende namen in het ontwerp (zoals "BIT engineer") zijn niet bindend. In de interface heet de kolom met de primaire beroepsrol "Profiel".
