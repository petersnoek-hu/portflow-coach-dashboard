# Gildes van Open-ICT

De gildes van Open-ICT, elk met zijn beroepsrol. Bij elke beroepsrol ([beroepsrollen.md](beroepsrollen.md)) hoort precies één gilde, met dezelfde code; in het dashboard is de beroepsrol daarom een veld van het gilde ([spec 018](../features/018-beroepsrol-in-gilde/spec.md)). Het dashboard leest deze tabel voor de knop "Open-ICT-gildes toevoegen" op de pagina Gilde toevoegen ([spec 006](../features/006-gildemeesters/spec.md), F14; spec 018, F4). Eén gilde per regel, in de vorm `| **CODE** | Gilde | Beroepsrol |`. Dit is de enige lijst met codes en namen van gildes en beroepsrollen.

| Code | Gilde | Beroepsrol |
|---|---|---|
| **UX** | UI/UX gilde | UI/UX designer |
| **BIT** | Business IT gilde | Business IT engineer |
| **CS** | Cybersecurity gilde | Cybersecurity engineer |
| **CI** | Cloud & Infra gilde | Cloud & Infra engineer |
| **FE** | Front-end gilde | Front-end developer |
| **BE** | Back-end gilde | Back-end developer |
| **AI** | AI gilde | AI engineer |
| **GD** | Game development gilde | Game developer |
| **TI** | Embedded technologie gilde | Embedded technologie engineer |
