# Gildes van Open-ICT

De gildes van Open-ICT. Bij elke beroepsrol ([beroepsrollen.md](beroepsrollen.md)) hoort precies één gilde, met dezelfde code. Het dashboard leest deze lijst voor de knop "Open-ICT-gildes toevoegen" op de pagina Gilde toevoegen ([spec 006](../features/006-gildemeesters/spec.md), F14). Eén gilde per regel, in de vorm `| **CODE** | Naam |`.

| Code | Gilde |
|---|---|
| **UX** | UI/UX gilde |
| **BIT** | Business IT gilde |
| **CS** | Cybersecurity gilde |
| **CI** | Cloud & Infra gilde |
| **FE** | Front-end gilde |
| **BE** | Back-end gilde |
| **AI** | AI gilde |
| **GD** | Game development gilde |
| **TI** | Embedded technologie gilde |
