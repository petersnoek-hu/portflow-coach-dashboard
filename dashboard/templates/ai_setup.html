AI-advies instellen

Bij een evaluatie kan een AI een advies over het niveau geven. Hieronder stel je de AI's in die je wilt gebruiken; op de pagina van een evaluatie kies je per keer welke. Het lokale model is het veiligst: daarbij gaat er niets van je laptop af.

Lokaal model (Ollama)

In vier stappen zet je een AI-model op deze laptop klaar. Het dashboard controleert na elke stap of het gelukt is. Het model draait in het programma Ollama, op je eigen laptop: er gaan geen gegevens van studenten naar internet.

Claude (via internet)

Let op: gebruik alleen AI-diensten die door de HU zijn goedgekeurd voor werk van studenten.

Met Claude gaat het materiaal van een evaluatie via internet naar Anthropic: de zelfevaluatie, LEF-teksten, eerdere beoordelingen, feedback en de inhoud van bewijsstukken, ook afbeeldingen. Namen worden vervangen door "Student", "Coach 1" enzovoort; in afbeeldingen en gescande documenten kan dat niet. Controleer daarom eerst of de HU het gebruik van Claude hiervoor toestaat.

{% if claude.error %}

Claude is ingesteld: sleutel {{ claude.key }}, model {{ claude.model }}{% if claude.approved %}; toestemming van de HU bevestigd op {{ claude.approved }}{% endif %}.{% if claude.saved %} De sleutel werkt.{% endif %}

{% else %}
  1. Maak een account in de Claude Console (of gebruik het account dat de HU je geeft) en zorg dat er tegoed is. Eén advies kost ongeveer 10 tot 30 cent.
  2. Maak onder API keys een sleutel aan en kopieer hem.
  3. Zet hieronder het vinkje, plak de sleutel en klik op Opslaan en controleren. Het dashboard controleert de sleutel bij Anthropic; dat kost niets.

De sleutel blijft op deze laptop, in de database van het dashboard; hij staat niet in reservekopieën en wordt nooit in de browser getoond.
