{# F29-F32: how much of the laptop the local model may use #}

De laptop ontlasten

Een lokaal model kan de laptop flink bezighouden. Hier begrens je hoeveel het mag gebruiken; dit geldt voor alle lokale modellen, vanaf het volgende advies.

Minder kernen: de laptop blijft beter bruikbaar, het advies duurt langer. Op een Mac rekent het model vooral op de grafische chip; daar maakt dit weinig uit.

Hoeveel materiaal per advies {% set choices = [("weinig", "Weinig", "het minste geheugen; bij een groot verzoek gaan veel bewijsstukken mee met alleen hun naam"), ("normaal", "Normaal", "ongeveer de helft van het materiaal van Veel"), ("veel", "Veel", "het meeste materiaal; enkele GB extra geheugen bovenop het model")] %} {% for value, label, note in choices %} {% endfor %}

Het model zelf moet altijd in het geheugen passen (ongeveer de grootte van het bestand); deze keuze bepaalt alleen het geheugen dat er bovenop komt.

Een groot verzoek op een laptop zonder grafische chip zwijgt vooral aan het begin lang, terwijl het model het materiaal leest. Zolang het model woorden schrijft, loopt het advies door. Van {{ ai_wait_range[0] }} tot {{ ai_wait_range[1] }} minuten; standaard {{ ai_wait_default }}.
